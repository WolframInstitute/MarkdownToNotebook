# Data Wrangling

Turning raw data into something you can compute with is usually a two-step
affair: first get the data into the Wolfram Language, then reshape it until the
rows and columns you care about are front and center. The workflows collected
here walk through both halves, from importing files, web pages and repository
data to selecting, filtering and summarizing the result as a structured
dataset.
